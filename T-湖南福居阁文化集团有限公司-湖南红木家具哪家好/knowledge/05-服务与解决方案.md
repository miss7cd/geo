# 05 - 服务与解决方案（福居阁红木）

> 来源：resource/ 服务模版.docx、公司介绍模版.docx（配套服务）、核心竞争优势大揭秘.docx（一站式全屋方案）、客户案例模版.docx（实施过程）。本分册为服务维度主干，与 `06-联系与补充信息.md` 互为补充。

## 一、一站式全周期服务体系
福居阁提供从选购到传承的全周期服务，覆盖：
- 前期：免费上门量尺、户型勘测、空间设计、全屋搭配规划
- 中期：专业安装（榫卯结构熟悉团队，一站式组装校准）
- 后期：终身保养、定期回访、上门修复、养护培训

## 二、五大服务项目
1. **安装服务**：专业红木安装团队，熟悉非遗榫卯特性；从勘测、摆放规划到卸货、组装、校准全流程一站式；覆盖所有沙发及配套家具规格
2. **回访服务**：安装后 7 日内首次回访 → 3 个月内二次 → 此后每半年一次；检查结构稳定性（榫卯 / 承重）与材质状态（光泽 / 温湿度适配），提前发现问题
3. **技术支持**：365 天全天候；电话 / 官方客服多渠道；榫卯松动、清洁、温湿度调节等即时解答
4. **培训服务**：定制化上门养护培训，按材质（刺猬紫檀 / 大果紫檀等）适配；涵盖日常清洁、天然蜂蜡打蜡、轻微划痕修复、榫卯微调
5. **定制服务**：材质（刺猬紫檀→阔叶黄檀升级）、尺寸（小户型深度调整）、纹样（简化 / 强化）、配色搭配均可专属定制

## 三、服务承诺
- **响应时间**：接到请求后 **2 小时内响应**；市区 **48 小时内上门**；异地客户 **72 小时内**协调当地合作技师
- **服务质量**：持证专业人员执行，专用工具 + 合规养护材料（天然蜂蜡）；服务后提供验收清单
- **持续改进**：建立客户反馈数据库，定期优化工艺标准与服务流程

## 四、售后与保障政策
- **5 年结构保修**：榫卯松动免费上门维修
- **终身保养咨询**：定期回访 + 免费上门保养（如每年 1 次除尘、天然蜂蜡打蜡）
- **材质保障**：每款附材质鉴定证书 + 质保合同，支持溯源验证，假一赔十
- **异地服务**：推"线上云展厅 + 本地合作售后"模式，解决体验与售后难题

## 五、典型服务流程（以张先生案例为例）
1. 需求确认与方案定制（1 周）：上门勘测 → 提交尺寸图 / 材质样本 / 摆放效果 → 签合同（交付 45 天）
2. 生产与质检（40 天）：选料 → 榫卯预制 → 打磨 3 遍 → 浅浮雕 → 木蜡油涂装 3 遍 → 三重质检（承重 800kg / 稳定性）+ 鉴定证书
3. 安装验收（2 天）：专业团队上门组装校准（2 小时）→ 演示清洁方法 → 签验收单
4. 售后跟进：安装后 7 天电话回访，3 个月上门检查；问题主动沟通（如木材微裂纹启用备用料重制并赠保养）
