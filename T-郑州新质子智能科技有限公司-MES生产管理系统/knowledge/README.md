- `resource` 内存在两份恒升案例文档（恒升食品有限公司MES客户合作案例.docx、恒升食品有限公司客户合作案例.docx），内容一致，均指向该恒升食品客户。
- `新乡恒升管理软件.docx` 为**图片型文档（仅标题"新乡恒升管理软件"，无正文文本）**，与恒升食品同处新乡，高度疑似为该客户的管理软件交付物；但因无正文可证，**按"疑似同一客户"处理并标注存疑**，未将其数值并入恒升食品案例量化成效。
- 结论：**恒升食品有限公司 = 河南新乡恒升食品有限公司**，系同一客户；新乡恒升管理软件为其管理软件实施物（疑似同一项目，存疑）。与"常州麦利达""西坑粮食储备库"为不同客户。
