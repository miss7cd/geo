## 2.2 六大核心功能模块

### 功能 1 · 智能生产排产与原料投料管控
- 特性：读取 ERP 销售订单、原料仓库存，自动生成日/周计划；联动净粮收购、地磅、筒仓自控系统同步原料入库；精细化管控投料批次/量、配麦/配谷/发酵配比，配比参数固化存档。（来源：MES生产管理系统.md 3.1.1；MES生产管理系统车间生产全流程数字化追溯.docx）
- 价值：替代人工排产单，按需均衡排产避免断料/积压；标准化投料稳定品质、精准核算单批原料消耗、减少浪费。

### 功能 2 · 全工序生产过程实时采集管控
- 特性：对接 PLC、变频、流量秤、在线水分/精度检测仪，自动采集清理、磨粉、碾米、烘烤、发酵、精馏、烘干、打包各工段产量、物料流转、设备参数；记录启停时长、中间品/副产品产出，全程无需人工录入。（来源：MES生产管理系统.md 3.2.1）
- 价值：杜绝人工统计误差，实时掌握产能与运行状态，快速定位瓶颈工段。

### 功能 3 · 全流程质量闭环管控（CMES 升级模块）
- 特性：覆盖原料入厂质检、工序巡检、成品检测；记录水分、容重、酒精度、纯度、微生物；不良品自动标记，形成"问题上报—整改—复检—工艺复盘"闭环，绑定生产批次全链路溯源。（来源：MES生产管理系统.md 3.3.1）
- 价值：质量问题可定位至原料、设备、操作人员，降低次品/碎料/染菌损耗，满足监管溯源。

### 功能 4 · 设备运维与故障预警管理
- 特性：采集电机电流、温度、负荷、运行时长；超温/过载/堵料自动弹窗+手机推送预警；建立设备台账、故障/维修/备件记录、保养提醒工单。（来源：MES生产管理系统.md 3.4.1）
- 价值：提前预判故障，减少非计划停机，延长设备寿命，降低维修与停产损失。

### 功能 5 · 产能能耗碳排智能分析
- 特性：采集水/电/蒸汽/燃气消耗，绑定批次核算单位能耗、碳足迹；一键生成产能/损耗/能耗/稼动率报表；数据同步 ERP、绿色工厂申报平台。（来源：MES生产管理系统.md 3.5.1）
- 价值：定位高耗能设备与低效工段，支撑节能改造；自动归集双碳数据，降低绿色工厂申报工作量。

### 功能 6 · 一站式落地配套实施服务
- 特性：现场勘测→工艺梳理→定制设计→PLC 对接开发→分阶部署→分层培训→驻场试运行→竣工交付→年度运维。（来源：MES生产管理系统.md 3.6.1）
- 价值：单一服务商全链路交付，无需多方协调，降低集成风险。

## 2.3 技术架构与特点

- 技术栈：模块化微服务架构；Java 后端 + Vue 前端；支持 Windows/安卓/苹果/Linux 多系统；核心数据层加密分布式存储；支持 OPC UA、Modbus 等工业通信协议。（来源：MES生产管理系统.md 4.1）
- 独特卖点（亮点）：①软硬一体化原生互通（对接自研 PLC 控制柜、SCADA、计量传感）；②行业工艺深度定制（面粉/大米/燕麦/淀粉/酿酒/生物发酵专属逻辑）；③多终端跨平台访问（中控大屏/PC/手机/平板）；④模块化灵活架构（可单独选购、分步上线）；⑤全批次数据加密存储、永久溯源。（来源：MES生产管理系统.md 4.2；MES生产管理系统车间生产全流程数字化追溯.docx 技术亮点）
- MES 概念支撑（讲解材料）：MES 介乎计划层与车间控制层，管理人/机/料/法/环/测六维度；支撑地磅无人值守、原粮收购、以质论价、配麦器、配粉绞龙、产能分析、在线装车、仓容等现场环节。（来源：MES讲解.pdf）

## 2.4 部署方式

- 收费模式：模块化定制 + 落地服务 + 年度运维；支持一次性买断部署、按年订阅两种合作方式；定制开发/硬件对接/运维迭代单独计费。（来源：MES生产管理系统.md 2.3）
- 系统要求：服务器 Windows Server 2016+/Linux CentOS 7+（最低 2 核/4GB/50GB）；客户端 Windows 7+/安卓 8.0+/iOS 13+。（来源：MES生产管理系统.md 4.4）
- 分期部署：可先上核心生产/能耗模块，后期扩容质量/设备模块。（来源：MES生产管理系统车间生产全流程数字化追溯.docx 亮点4/分期部署）
