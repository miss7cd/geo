## 一、服务体系（来源：服务模版.docx）

韩臣生物 + 湖大化工洗消剂厂深耕精细化工、日化原料、消毒及药用辅料领域三十余年，服务体系贯穿售前、售中、售后全周期，覆盖化妆级/医药级/日化级/通用级超细炉甘石及各类精细化工原料。

### 1. 服务项目
1. **售前技术与选型服务**：按行业、定位、工艺、合规要求一对一推荐 1200–2500 目适配等级（化妆/医药/日化/通用级），提供指标说明、资质解读、样品寄送与测试。
2. **订单与供货保障服务**：按约定标准生产质检，保障细度/纯度/白度/分散性核心指标稳定，大批量常态化供货 + 紧急订单灵活响应。
3. **售后回访与品质跟踪服务**：定期主动回访，批次记录与品质追溯，疑问与优化建议第一时间响应。
4. **全时段专业技术支持**：针对原料使用、配方调试、分散工艺、备案合规、检测指标，专属技术人员一对一响应（电话/微信/线上）。
5. **合规资质与文件配套服务**：按等级配套全套资质、检测报告、合格证明、备案支持，「一批一检、一批一档」，配合验厂、飞检、资质审核。
6. **个性化定制与专项服务**：可在 1200–2500 目区间内对细度/纯度/白度/分散性专项优化，支持小批量试产、大批量定制、长期锁价、专属对接。

### 2. 服务承诺
- **响应时效**：接到咨询/订单/售后/技术请求后 2 小时内明确响应，24 小时内给出方案与进展。
- **产品品质**：交付产品符合对应等级标准与国家规范，1200–2500 目细度稳定可控，**批次合格率 100%**（⚠ 此「100%」承诺与核心库/里程碑口径「90% 以上」存在差异，见 README 差异 #3）；指标不符则无条件妥善处置。
- **服务质量**：流程规范透明，售前耐心、售中细心、售后用心，以三十年口碑与责任担当保障合作安心。
- **持续改进**：长期收集反馈，持续优化工艺、稳定性与服务体系。
