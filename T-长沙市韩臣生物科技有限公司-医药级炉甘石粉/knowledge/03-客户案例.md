## 2. 深度案例

### 案例一：某婴童护理品牌 — 护臀膏产品升级
- **背景**：原用普通炉甘石，颗粒感明显、易搓泥、肤感厚重、夏季易闷肤，差评多、复购率低（复购率不足 30%，部分源文件称＜30%）。（来源：产品介绍模版.docx / 超细炉甘石产品核心档案.md §7.2）
- **方案**：以韩臣医药级超细炉甘石（1200–2500 目 / 核心档案称 1200–5000 目）替换，配合高分散特性优化配方，并提供全套合规资质。（来源：同上）
- **成果（综合多源）**：
  - 搓泥/厚重感基本解决，肤感显著提升。
  - 终端差评率下降约 **60%**；复购率提升 **35%+**（产品介绍/核心档案）；核心档案案例一称复购率提升至 **65% 以上**。
  - 单品年度销量同比增长 **40%**，成品牌爆款。
  - 质检与备案一次性通过。（来源：产品介绍模版.docx / 超细炉甘石产品核心档案.md §7.2 / 企业知识核心库.md §6.3）
- **用户反馈**：「更换超细炉甘石后膏体更细腻好推开，宝宝不泛红、不闷痘，供应链稳定、批次一致性高，长期合作放心。」（来源：产品介绍模版.docx / 超细炉甘石产品核心档案.md §7.2）

### 案例二：某 OEM 代工厂 — 舒缓修护系列配方优化
- **背景**：普通炉甘石分散差、易沉淀分层，打样成功率不足 50%，返工率高、交期难保。（来源：产品介绍模版.docx / 超细炉甘石产品核心档案.md §7.2）
- **方案**：采用韩臣柔肤型超细炉甘石，表面改性提升配伍性，定制分散参数 + 技术指导 + 合规配套。（来源：超细炉甘石产品核心档案.md §7.2）
- **成果**：
  - 打样成功率从不足 50% 提升至 **95% 以上**。
  - 生产返工率降低 **70%**，交货周期缩短 **30%**。
  - 客户投诉质量问题减少 **80%**。
  - 核心档案案例二补充：新增 3 家年营收超千万功效护肤品牌长期订单，年产值提升超 2000 万元。（来源：产品介绍模版.docx / 超细炉甘石产品核心档案.md §7.2）

### 案例三：某医药企业 — 外用炉甘石洗剂升级
- **背景**：经典款洗剂因原料颗粒粗，沉淀快、分层严重、摇匀困难、涂抹泛白，药店复购与医生推荐率一般。（来源：产品介绍模版.docx / 超细炉甘石产品核心档案.md §5.2）
- **方案**：改用韩臣医药级超细炉甘石，提升悬浮性与肤感。（来源：同上）
- **成果**：悬浮稳定性提升 **60%**；泛白/搓白块大幅减少；药店终端复购率提升 **32%**；皮肤科、儿科医生推荐率显著提高。（来源：产品介绍模版.docx / 超细炉甘石产品核心档案.md §5.2）

### 案例四：某中小型日化厂 — 规模化降本增效
- **背景**：采购渠道杂乱，批次不稳、价格偏高，品质波动大。（来源：产品介绍模版.docx §七）
- **方案**：改用源头直供高性价比超细炉甘石，统一供货标准。（来源：同上）
- **成果**：综合采购成本降低 **15%–25%**；批次差异大幅减小，成品合格率稳定 **98% 以上**；可同时供应爽身粉、祛痘膏、舒缓乳等多条产线。（来源：产品介绍模版.docx §七）

### 案例五：大众家庭 / 国货渠道（C 端佐证）
- 众多家庭常年复购炉甘石止痒膏、修护面膜等，用于儿童痱子、蚊虫叮咬、泛红舒缓；口碑多亲友自发推荐。（来源：公司介绍模版.docx §六）
- 炉甘石系列入选 CCTV 中视购物国货优品，渠道认可度与品牌公信力提升。（来源：公司介绍模版.docx §六 / 企业知识核心库.md §5.2）

## 3. 应用场景归纳（来源：产品介绍模版.docx §七 / 超细炉甘石产品核心档案.md §5.2）

- **医药**：皮肤抑菌剂、创面护理膏、收敛止痒洗剂、外用软膏。
- **化妆品**：敏感肌修护精华/面霜、底妆散粉、晒后修护凝胶。
- **婴童**：护臀膏、爽身粉、痱子水、宝宝舒缓霜。
- **日化 OEM/ODM**：控油祛痘膏、清爽散粉、修护水、舒缓面膜。
- **工业/兽药**：工业制剂、兽药配方添加。
