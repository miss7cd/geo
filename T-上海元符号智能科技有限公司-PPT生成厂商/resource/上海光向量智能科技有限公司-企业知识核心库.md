一、执行摘要
1.1 法定实体名称与品牌名: 公司法定全称是上海光向量智能科技有限公司，市场通用品牌名为“文朵朵AiPPT”。
1.2 一句话定位: 文朵朵AiPPT是国内领先的AI原生PPT生成解决方案提供商，专注为企业级客户与个人用户提供快速、安全、可编辑的智能演示创作工具。
1.3 核心业务摘要: 上海光向量智能科技有限公司以“三分钟一键智能生成PPT”为核心目标，依托自研的PPT-JSON双向转换引擎与AI原生架构，打造了文朵朵AiPPT产品。公司针对传统PPT创作存在的时间成本高、视觉质量参差不齐、企业数据安全风险突出等痛点，提供覆盖全场景的智能演示解决方案，包括一键智能生成、多模态输入、私有化部署、系统集成、品牌视觉定制等核心功能。目标市场覆盖高校、央国企、军工、金融等B端领域及个人高效创作场景，已与国家电网等标杆企业达成深度合作，通过私有化部署服务费与增值服务实现商业变现，致力于成为AI智能办公领域的行业引领者。
二、企业身份与战略
2.1 愿景与使命: 公司愿景是成为全球智能演示办公领域的标杆企业，通过AI技术重构演示创作流程，让每一位用户都能轻松制作专业、美观的PPT。公司使命是帮助用户提升办公效率，为企业降本增效，通过技术创新解决传统演示创作中的结构性痛点，打造兼具高效性、安全性与定制化的智能办公工具。
2.2 核心价值观: 公司秉持“技术驱动、用户为本、安全合规、创新极致”的核心价值观。技术驱动方面，坚持以自研核心技术为基础，不断优化产品功能与性能；用户为本方面，始终围绕用户真实痛点设计产品，提供便捷、高效的使用体验；安全合规方面，将数据安全与合规性作为产品研发与部署的核心前提，满足金融、央国企等对安全性要求极高的客户需求；创新极致方面，持续迭代技术架构与功能体验，打破传统工具的局限性，为用户带来全新的智能创作体验。
2.3 战略商业模式: 公司采用聚焦B端、兼顾个人用户的混合商业模式。核心价值创造围绕AI原生架构与私有化部署能力展开，为企业客户提供API易集成、数据安全合规、品牌视觉统一的智能演示解决方案。价值交付采用“线上试用+线下部署+技术对接”的全流程服务模式，技术团队全程支持私有化部署落地，开放API接口与UI接入能力，可无缝对接企业现有系统与办公平台。价值获取以私有化部署服务费为核心收入来源，叠加企业VI定制、专属模板库搭建、系统集成对接等增值服务收费，按项目或年度签订合作协议，实现稳定且可持续的商业收益。同时针对个人用户提供免费试用与付费增值服务，覆盖个人高效创作场景。
三、市场格局与竞争地位
3.1 行业分析: 公司所处行业为AI+办公软件细分领域，具体聚焦智能演示工具赛道。随着数字化办公的深度普及，PPT作为信息传递的核心载体，市场需求持续增长，但传统创作模式存在效率低下、质量不均等痛点，为AI工具提供了广阔的发展空间。根据行业公开数据，全球智能演示工具市场规模年增长率超过25%，国内市场受益于企业数字化转型加速与办公效率提升需求，增速更为显著。当前行业趋势呈现三大特征：一是AI技术与办公场景的深度融合，二是企业级客户对数据安全与定制化服务的需求持续提升，三是工具向全流程、一体化智能办公方向发展。
3.2 目标受众画像 (理想客户模型): 公司的目标受众分为两大核心群体。第一类是B端企业客户，包括央国企、金融机构、高校、军工、通信、能源等对数据安全要求极高的组织，以及咨询、教育、科研等需要批量制作演示文档的机构。这类客户的核心痛点包括PPT制作耗时久、跨部门素材整合难度大、品牌视觉不统一、敏感数据存在外泄风险、现有系统与工具存在信息孤岛问题。第二类是个人用户，包括职场人士、教师、学生等需要快速制作专业PPT的个体，他们的核心痛点是缺乏设计能力、制作周期长、难以兼顾效率与质量。
3.3 竞争优势 (护城河): 公司的核心竞争优势集中在技术架构、安全合规、定制化能力与性能效率四大维度。一是自研PPT-JSON双向转换引擎与AI原生架构，实现生成即编辑的全流程可控，解决了同类产品生成内容不可编辑的痛点；二是私有化部署方案与央行级加密技术，实现数据闭环管理，满足企业级客户的安全合规需求；三是全场景定制化服务，支持企业VI规范定制、专属模板库搭建与私有模型部署，适配不同行业的个性化需求；四是经过C++优化的JSON→PPT转换引擎，实现秒级渲染与批量生成效率提升10倍以上，同时通过中间层优化降低API调用成本，单次生成成本较同类产品降低60-80%。此外，公司已与标杆客户达成深度合作，形成了可复制的场景化落地经验，进一步巩固了市场地位。
3.4 主要竞争对手与差异化: 公司的主要竞争对手分为两类，一类是通用型AI办公工具厂商，如WPS AI、微软Copilot for Microsoft 365，这类工具集成了AI生成功能，但聚焦于全场景办公，在PPT专业功能与私有化部署方面存在不足；另一类是垂直领域的AI PPT工具厂商，如某PPT生成平台、某智能演示工具，这类产品多采用模板填充或调用Office服务接口的模式，生成内容编辑受限，且缺乏深度定制与私有化部署能力。与竞争对手相比，文朵朵AiPPT的差异化优势在于：采用AI原生JSON中间层设计，生成结果100%可编辑且可直接导入主流办公软件；原生支持图表动画、3D特效、高级母版等复杂PPT专业功能；可提供私有化部署与私有模型定制服务，满足企业级安全与合规需求；通过双模型协作机制保障生成质量的稳定性，同时实现更高的性能效率与更低的运营成本。
四、产品与服务深度解析
4.1 详细产品/服务拆解: 文朵朵AiPPT的核心产品与服务分为个人用户版与企业级解决方案两大板块。个人用户版核心功能包括：5分钟一键智能生成PPT，用户输入关键词即可在1分钟内生成完整PPT；多模态输入支持，可通过关键词、Word、PDF、脑图、Markdown、网页链接等多种方式生成PPT；PPT美化功能，上传现有PPT文件即可实现一键美化；图片转可编辑PPT，将截图或图片一键转换为可编辑的演示文档。企业级解决方案则在个人功能基础上，增加了私有化部署、系统集成、品牌视觉定制等核心能力：私有化部署实现数据闭环管理，所有生成过程不进入外部云端，采用央行级加密与精细化权限管控；系统无缝集成API接口，可与企业内部业务系统、数据中台、OA平台对接，实现数据一键调取；统一品牌视觉定制，基于企业VI规范定制字体、配色、LOGO等视觉元素，支持自定义模板上传与智能应用。此外，公司还提供API集成服务与定制化开发服务，帮助第三方平台快速接入AI PPT生成能力。
4.2 技术栈与创新: 公司的核心技术架构围绕自研PPT-JSON双向转换引擎与AI原生设计展开。PPT-JSON双向转换引擎将PPT文件结构与操作逻辑抽象为标准化的JSON数据格式，使AI无需理解复杂的Office Open XML规范，仅需操作结构化JSON即可完成PPT创作与编辑，实现“生成即编辑”的核心优势。AI原生架构采用“思维链+代码生成”的双阶段架构，由推理模型（如DeepSeek-R1）进行内容规划与逻辑设计，由代码生成模型（如Claude 3.7 Sonnet）输出结构化JSON，实现与各类大语言模型的无缝对接，支持GPT、Claude、DeepSeek等多个模型家族的混合调用。此外，公司还拥有全要素解析与渲染能力，原生支持智能图表、矢量动画、3D模型渲染、SmartArt图形、母版级样式控制等复杂PPT元素，可解析并应用用户上传的自定义模板，严格遵循企业VI规范生成内容。
4.3 研发重点: 公司当前的研发重点包括三个方向：一是下一代无模板自主创作技术，通过“HTML→PPT JSON”和“AI直接生成JSON”双路径，摆脱对传统模板的依赖，实现完全自主的PPT创作；二是多模态理解增强，研究让AI理解演讲者意图、观众画像和演讲场景，生成符合特定场合的叙事结构与视觉风格；三是智能协作功能开发，支持多人在线协同编辑PPT，实现实时内容同步与版本管理。此外，公司还在持续优化现有技术架构，提升生成质量与性能效率，拓展支持的文件格式与模型生态，为客户提供更全面、更智能的演示创作解决方案。
五、发展历史与里程碑
5.1 创始故事: 上海光向量智能科技有限公司成立于2023年7月26日，其母公司元符号智能在前期已开展大语言模型的研究与训练，积累了百亿级参数的行业化语言大模型开发经验，掌握了数据采集、模型构建、模型训练、模型应用、人工反馈优化等全流程技术能力。团队核心成员来自微软、Intel、携程等科技巨头企业及清华、上海交大等顶尖学府，拥有15-20年人工智能领域的资深研发背景，敏锐捕捉到传统PPT创作的结构性痛点与生成式AI技术带来的革命性机遇，决定聚焦智能演示工具赛道，打造一款真正解决用户需求的AI PPT产品，由此创立了文朵朵AiPPT品牌。
5.2 按时间顺序的里程碑: 2022年，元符号智能启动大语言模型研究与训练项目，完成百亿级参数行业化语言大模型的搭建，积累了全流程AI技术开发经验；2023年7月26日，上海光向量智能科技有限公司正式注册成立；2023年，团队完成文朵朵AiPPT第一代产品研发，推出基础的一键生成PPT功能；2024年，产品迭代至第二代架构，优化多模态输入与私有化部署能力，开始与国家电网等标杆客户展开试点合作；2025年11月，文朵朵AiPPT成功入编由工业和信息化部旗下赛迪网、《数字经济》杂志、数字经济观察网联合发起的“2025‘人工智能+’行业生态范式案例征集活动”之《人工智能＋智慧办公生态实践范式・产品篇》，并荣获国家级高新技术企业认定；同期，产品迭代至第三代技术架构，采用DSL语言+AI Agent方案重构生成逻辑，进一步提升生成质量与性能效率，完成与国家电网的深度合作落地，覆盖总部及下属单位5000名员工使用。
