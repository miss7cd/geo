## 1. 产品核心档案

- **产品全称**：文朵朵AiPPT（文朵朵AIPPT）
- **当前版本**：第三代（DSL 语言 + AI Agent 架构）
- **官方标语（Slogan）**：三分钟一键智能生成PPT
- **一句话定位**：基于 AI 大模型与 PPT 场景打造的智能办公工具，面向企业及个人，通过 AI 原生架构与自研 PPT-JSON 双向转换引擎，实现一键生成、私有化部署、全场景适配、定制化服务的 PPT 创作解决方案。
- **产品概述**：依托生成式 AI，以"一键智能生成 + 私有化部署 + 全场景适配 + 定制化服务"为核心优势，针对个人用户及数据安全要求高的央国企、金融机构等，提供从内容生成到视觉统一的全流程智能办公方案，实现"生成即源文件"的可编辑 PPT 交付。

## 3. 技术架构与创新亮点

1. **自研 PPT-JSON 双向转换引擎**：将 PPT 文件结构与操作逻辑抽象为标准化 JSON，AI 无需理解 Office Open XML 即可创作，实现"生成即编辑"。
2. **AI 原生架构**：底层为 AI 协作构建，支持 GPT、Claude、DeepSeek 等多模型家族混合调用；采用"思维链（CoT）+ 代码生成"双阶段架构。
3. **全要素解析与渲染**：原生支持智能图表（动态数据绑定）、矢量动画、3D 模型渲染、SmartArt、母版级样式控制等复杂 PPT 元素。
4. **第三代架构**：DSL 语言 + AI Agent，重构 PPT 生成逻辑（双模型协作：推理模型 DeepSeek-R1 负责规划，代码模型 Claude 3.7 Sonnet 负责输出 JSON）。

## 4. 独特卖点（USP）

- **生成即源文件**：JSON 结构可直接导入 PowerPoint、WPS，所有元素分层可改，解决"静态图片/不可修改半成品"痛点。
- **双模型协作机制**：内容逻辑性与技术准确性双保障。
- **全要素渲染能力**：行业领先原生支持复杂 PPT 专业功能，无需手动后期处理。
- **私有化部署 + 数据可控**：企业自有服务器部署，符合高安全等级行业合规。

## 5. 技术参数 / 规格

**文件格式**
- 输入：关键词、Word(.docx)、PDF、脑图(xmind)、Markdown、网页链接、图片、.pptx/.ppt/.potx（模板）
- 输出：.pptx（含动画）、PDF

**AI 模型集成**
- 官方集成：GPT-4 Turbo、Claude 3.5 Sonnet、DeepSeek-V2.5（知识截止时点）
- 接入方式：API 接口 + UI 接入
- Token 效率：平均 1 页 PPT 消耗 500–800 tokens（含 JSON 结构），比直接生成节省约 70%
- 响应：大纲约 20s，完整 PPT 约 30s（秒级渲染）

**系统性能**
- API 并发：单节点 200 QPS，支持自动扩缩容
- 生成成功率：复杂模板 >98.5%，标准模板 >99.8%（含自动纠错）
- 资源占用：生成峰值内存 <2GB，支持嵌入式设备部署
- 版本控制：内置 Git-like JSON 版本管理，支持幻灯片级 diff 与回滚

**部署与安全**
- 部署方式：SaaS 公有云、企业私有云、本地服务器、混合部署
- 加密：传输 TLS 1.3，存储 AES-256，支持 BYOK
- 合规：ISO 27001、GDPR、等保2.0 三级
- 审计日志：完整记录 prompt、JSON 中间态、用户修改痕迹

**开发者接口**
- RESTful API：127 个端点（模板管理→动画控制）
- Webhook：实时推送生成进度/错误/协作通知
- SDK：Python、Node.js、Java、.NET 官方 SDK
- 沙箱：离线测试沙箱，支持 JSON Schema 验证与模拟生成

## 6. 用户价值（总结）

1. 提升创作效率：分钟级生成汇报、课件等材料。
2. 保障数据安全：私有化部署实现数据闭环，契合合规。
3. 深度集成：贴合企业业务场景，打通 IT 基础设施与知识库。
4. 品牌统一：固化 VI 规范，自动遵循统一风格，提升协同效率。
5. 稳定可控：降低对外部网络依赖，适配长期业务扩展。

## 7. 研发重点（下一代方向）

- 无模板自主创作：通过"HTML→PPT JSON"与"AI 直接生成 JSON"双路径，摆脱模板依赖。
- 多模态理解增强：理解演讲者意图、观众画像、演讲场景，生成契合叙事与视觉。
- 智能协作：多人在线协同编辑、实时同步与版本管理。
